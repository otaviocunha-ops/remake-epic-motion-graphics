# Runtime and portability

Python 3.10–3.14, Node.js 20+ and FFmpeg/ffprobe on PATH are required. Bootstrap downloads pinned Python/npm packages and the matching Playwright Chromium. Setup needs internet; rendering uses local assets and works offline afterwards. The default demo uses a system sans font; for reproducible typography across computers, bundle a licensed font in each film and declare @font-face. Chromium rasterization/GPU/OS differences can still affect pixels; the skill guarantees a frame-driven workflow, not universal pixel identity.

Run `python scripts/bootstrap.py` (macOS/Linux often `python3`). It creates .venv. Thereafter use `.venv/bin/python scripts/remake.py ...` on macOS/Linux or `.venv\Scripts\python.exe scripts\remake.py ...` on Windows. Commands accept paths with spaces when quoted; no shell-specific environment assignments are needed. --ffmpeg and --ffprobe accept explicit binary paths; --node selects Node. Commands work from any directory, with projects anywhere. Render calls set their working directory to the film internally.

FFmpeg install: macOS `brew install ffmpeg`; Debian/Ubuntu `sudo apt-get install ffmpeg`; Windows `winget install --id Gyan.FFmpeg`, then reopen the terminal. Node/Python must be installed first. Use operating-system package managers according to your environment's policy. Containers are optional; see Dockerfile. A headless browser needs OS libraries: on Linux use `node node_modules/playwright/cli.js install --with-deps chromium` with appropriate system permissions. Sandboxed tools may need approval for a specific browser launch; never universally add --no-sandbox or --disable-gpu. --webgl enables SwiftShader.

`init`: creates a self-contained film scaffold and copies core.js, so FILM need not sit beside the skill. `analyze`: extracts reference pixels/audio and proposed cuts. `csv-to-js`: loads measurement arrays without fetch. `render --frames`: diagnostic stills and comparison sheet. `render --full`: all frames. `verify`: frame sequence, dimensions and shot coverage. `encode`: FILM.mp4 from complete rendered frames and optional audio/mix.wav. `sync`: synchronized comparison MP4. `demo`: original geometric motion example plus synthetic tone, no third-party footage. These commands assist reconstruction; they do not automatically reverse engineer a whole film.

External STT/TTS, native app capture, licensed media searches and temporal shutter compositing are optional capabilities of the agent/film. No API keys or provider accounts are required for the included demo. Store secrets outside the repository.

Some upstream helper defaults (BG grid/camera centers) assume 1920×1080. For another resolution, use measured film-specific helpers; the viewport itself is never silently scaled. The original source examples and shell commands are archival: read toolkit-adaptations.md for their mapping.
