# Toolkit command mapping

The original prompts/playbook/examples are preserved source references. Their legacy shell commands target engine/upstream/, not the portable renderer adapter. For new films, SKILL.md and scripts/remake.py are authoritative: init replaces manual mkdir/cp, analyze replaces extraction/probing/contact sheets, render --frames replaces the old frames/compare command, render --full replaces full, encode and sync replace environment-variable commands. The core API remains unchanged.

Original example-monkey/sting source and audio helpers are included for study. Downloaded tracks, voice, reference footage and generated frames are omitted. Supply their required licensed inputs to run legacy audio scripts; use the procedural demo for a fully self-contained runnable example. Fonts in old example pages may be remote; the portable template has no network-loaded assets. The portable page uses local assets/core.js and dimensions from film-settings.js, so film directories can live anywhere.

Original instructions to always spawn agents, prohibit reference audio reuse or run every browser unsandboxed are template conventions. Follow the user's resolved audio choices, available agent permissions and the execution tool's actual sandbox policy. No private absolute source paths are included.
