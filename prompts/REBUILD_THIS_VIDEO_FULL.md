<engine>
One HTML page, #stage 1920x1080 overflow hidden, class .a{position:absolute}. window.seek(t): F=t*30; stage.innerHTML = render(F). Pure function of F: no timers, no CSS transitions/animations, no Math.random.
Helpers (use exactly):
- cl(x,a=0,b=1) clamp; lerp(a,b,t); inv(a,b,x)=cl((x-a)/(b-a)).
- E.ioS = t*t*(3-2t); E.lin = t.
- kf(F, [[f,v],...], ease=lin): before first key → first value; after last → last value; between keys lerp with ease((F-f0)/(f1-f0)); v may be a number or an array (lerp elementwise).
- mixHex(a,b,t) blends two #rrggbb.
- SVG motion-blur filters in a hidden <svg><defs>: id mbx{b} = feGaussianBlur stdDeviation="b 0" for b in 16,40,60 (x -20%, width 140%).
